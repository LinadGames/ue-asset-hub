# UE Asset Hub

Вебзастосунок-каталог безкоштовних ассетів для Unreal Engine (моделі, матеріали, Blueprint-системи, плагіни), де розробники публікують свої ресурси, а інші можуть їх знаходити, оцінювати й завантажувати.

## Проблема, мета та цільова аудиторія

**Проблема:** безкоштовні ассети для UE розкидані по GitHub, форумах, Discord-серверах і YouTube. Важко знайти потрібне, незрозуміло, з якою версією рушія ассет сумісний, немає відгуків.

**Мета:** зібрати безкоштовні ассети в одному місці з пошуком, фільтром за версією UE та модерацією.

**Цільова аудиторія:** інді-розробники, студенти, моддери, невеликі команди без бюджету на платні ассети.

## Ролі користувачів

| Роль | Можливості |
|---|---|
| Гість | Переглядає каталог, шукає та фільтрує ассети |
| Користувач | Завантажує та публікує ассети, залишає оцінки, відгуки й скарги |
| Модератор | Перевіряє нові ассети, розглядає скарги |
| Адміністратор | Керує користувачами, ролями, категоріями та версіями UE |

## Основні функції

- реєстрація та вхід
- каталог із пошуком і фільтрами (категорія, версія UE, ліцензія)
- публікація ассета з модерацією
- оцінки, відгуки та скарги
- керування користувачами й категоріями
